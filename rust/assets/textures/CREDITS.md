# Texturas PBR de naves3d: fuentes y licencias

Todo el material de `tools/naves3d/web/textures/` (set web, 1024 px) y `tools/naves3d/blender/textures/` (set Blender, 2K/4K) es **CC0 (dominio público)**: escaneos de [Poly Haven](https://polyhaven.com) y [ambientCG](https://ambientcg.com), regradados aquí, o texturas procedurales generadas con numpy para este proyecto (`tools/naves3d/blender/textures/_src/`). No hace falta atribución; se lista igual para trazabilidad.

Convenciones: `albedo.jpg` en sRGB; `normal.jpg` en convención OpenGL (+Y arriba, la que esperan three.js y Blender); `arm.jpg` lineal con R = oclusión ambiental, G = rugosidad, B = metalicidad (el ORM de glTF). `tile` en `manifest.json` = metros que cubre una repetición de la textura.
